# MongoDB Atlas Admin API - V2: Quickstart for Partners

Welcome to the documentation site for the MongoDB Atlas Admin API - V2 partner quickstart. These guides show ISV and Technology Partners how to call Atlas Admin API endpoints on behalf of their users with OAuth 2.1 delegated access tokens.

---

## Get started

> [!TIP]
> **Open the [interactive docs site](docs/)** — a guided walkthrough with an interactive OAuth flow explorer, environment switcher, and rendered guides.

| Guide | Description |
|---|---|
| [Partner Onboarding](docs/PARTNER.md) | Register with MongoDB, receive OAuth credentials, and integrate the flow into your product. |
| [Partner Integration Guide](docs/README.md) | Obtain and use access tokens, call the Atlas Admin API, and run the demo server. |

## What you'll learn

- **How delegated access works** — users log in to Atlas via standard OAuth; your app receives a short-lived, user-scoped token.
- **How to get onboarded** — MongoDB provisions your OAuth app during Early Access (invite-only).
- **How to call the Atlas Admin API** — list organizations, create projects, and provision clusters on behalf of your users.
- **How to test end-to-end** — set up a test Atlas account and run the included FastAPI demo server.
